# 🚀 Alnova AI — Your AI-Powered Career Copilot

**Alnova AI** is an AI-powered career assistance platform designed to help students and job seekers prepare for interviews, create resumes, generate study notes, and improve their career skills.

## ✨ Features

- 💬 **AI Chat:** Get answers to questions and assistance with learning.
- 🎤 **AI Interview:** Practice interview questions and improve your interview preparation.
- 📝 **AI Notes:** Generate helpful notes for learning and revision.
- 🧠 **AI Quiz:** Test your knowledge with AI-powered quizzes.
- 📄 **AI Resume:** Create and improve your resume for career opportunities.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **AI Integration:** AI API integration (depending on your configuration)

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AlnawazAhmad/Alnova-AI.git
```

### 2. Open the Project

```bash
cd Alnova-AI
```

### 3. Set Up the Backend

Open a terminal in the backend folder and install the dependencies listed in your `requirements.txt`, if available.

```bash
pip install -r requirements.txt
```

### 4. Run the Backend

Run the backend using the command specified in your project's setup instructions.

### 5. Launch the Frontend

Open the main HTML file in your browser or use the development server configured for your project.
